# Product Hunt

## Name

Claude Notch

## Tagline

Every Claude account open at once, limits by the notch

## Description

Run the Claude desktop app once per account, each signed in on its own, and see every account's 5-hour and weekly limits beside the MacBook notch. Switch with ⌥⌘1, 2, 3. Sign-in goes to the right copy. Free, for macOS 26.
