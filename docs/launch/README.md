# Launch kit

Drafts for you to post. Nothing here has been posted, and nothing will be unless you post it.

| File | Channel | Limits it's written to |
| --- | --- | --- |
| [show-hn.md](show-hn.md) | Hacker News, Show HN | Title 80 characters |
| [reddit-claudeai.md](reddit-claudeai.md) | r/ClaudeAI | Title 300 characters |
| [x-thread.md](x-thread.md) | X | 280 characters a post, a link counts as 23 |
| [product-hunt.md](product-hunt.md) | Product Hunt | Name 40, tagline 60, description 260 |
| [press-kit.md](press-kit.md) | Anyone writing about it | Name, one-liners, assets |

`node docs/launch/check.mjs` checks each draft against those limits.

## Before posting

1. **Licence.** The repo has none yet, so the drafts say "free" and "source on GitHub", never "open source". If you add MIT, change those lines to "free and open source (MIT)".
2. **The legal read** in `docs/BACKLOG.md` (Needs the user, 5). The drafts describe several accounts as personal, work and client accounts, and never suggest using accounts to get more usage.
3. **Try the one line** on a Mac that doesn't have it: `curl -fsSL https://dougwithseismic.github.io/claude-multi-account/install.sh | zsh`.
4. **Fill the brackets.** Each draft has one or two `[…]` spots for something only you can say, like why you built it. Delete them if you'd rather not.
5. **Each channel's rules.** r/ClaudeAI wants a flair and asks that posts about your own project say so; Show HN needs something people can try now. Read the current rules on the day, as they change.

Post Show HN and Reddit at different times, and stay around for a few hours after each to answer questions.
